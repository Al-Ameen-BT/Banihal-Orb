Factory reset

This erases everything: all rules, access lists, network rules, users, MFA enrolments, audit log, settings, imported lists and the SSL certificate. The console returns to first-run setup (admin / admin@123). Squid's own squid.conf is not touched. A snapshot is saved on the server first, but you should take a backup and download it before doing this.
